# 통해 (Tonghae)

이주노동자가 집 계약·월급 문제처럼 실수 한 번이 큰 손해로 이어지는 대화를 할 때, 무엇을 물어야 하는지 미리 준비해 주고 현장에서는 한국어로 대신 말해 주는 앱입니다.

**바로 열기: https://ssoyoum.github.io/tonghae/**

휴대폰에서 열고 "홈 화면에 설치"를 누르면 앱처럼 설치됩니다. iPhone은 Safari 공유 버튼에서 "홈 화면에 추가"를 고르세요.

## 할 수 있는 것
- **준비:** 상황별 필수 체크리스트와 한국어 대본(모국어 뜻·발음)을 소리로 듣기
- **현장:** 추천 문장을 누르거나 모국어로 말하면 한국어로 대신 말하기, 상대방의 한국어는 모국어로 번역, 위험 신호(본인 명의가 아닌 계좌로 송금 요구 등) 경고
- **정리:** 합의 금액, 놓친 항목, 다음 할 일, 도움 기관
- **연습:** AI 집주인·사장님과 영상통화처럼 롤플레이, 한국어로 말해서 대답하기
- **지원 언어:** 중국어, 베트남어, 태국어 (국내 체류외국인 국적 1~3위)

## 프로토타입 범위
- 상대방 대사와 롤플레이는 정해진 시나리오로 동작합니다. 출시 버전에서는 LLM이 즉흥으로 대답합니다.
- 한국어 음성은 브라우저 음성 합성(TTS), 음성 인식은 브라우저 음성 인식을 씁니다. Edge 또는 Chrome을 권장합니다.
- 번역은 무료 번역 API(MyMemory)를 써서 하루 사용량 제한이 있습니다.
- 대본·체크리스트·설명 카드는 오프라인에서도 열립니다. 번역과 음성 인식은 인터넷이 필요합니다.
- 이름·체류 정보는 모두 예시입니다. 중국어·베트남어·태국어 문장은 원어민 검수 전입니다.

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 기획 설명 화면과 앱 전체 (단일 파일) |
| `manifest.webmanifest` | 앱 이름·아이콘·바로가기 (홈 화면 설치용) |
| `sw.js` | 오프라인 캐시 |
| `icons/`, `og.png` | 앱 아이콘, 링크 미리보기 이미지 |
