AI 활용

네 가지 AI 기술이 각자 한 가지 일을 맡습니다

STT · 음성 인식

듣기

입력 상대·사용자 음성 → 출력 텍스트 + 언어 태그

  • 5개 언어: 한국어·영어·중국어·베트남어·태국어
  • 클라우드 STT(Chirp)와 Whisper 계열을 소음 조건별 오류율로 비교
  • 스트리밍으로 지연 단축
LLM · 대화 엔진

판단하고 추천하기

입력 발화 + 상황 + 스크립트 진행 상태 → 출력 JSON

  • 모국어 요약, 다음 문장 2~3개, 확인된 스크립트 항목
  • 아직 묻지 않은 항목을 먼저 추천
  • 모국어 → 공손한 한국어(해요체) 변환 + 역번역
RAG · 근거 검색

근거 대기

입력 상황 + 질문 → 출력 근거 문단 + 출처

  • 공식 문서를 문단 단위로 임베딩해 벡터 DB에 저장
  • 스크립트·안내 문장은 근거에서만 생성
  • 법률 판단은 하지 않도록 차단
