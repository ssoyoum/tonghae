이 공개 페이지

서비스 소개·설치 안내용입니다. 이 페이지에서는 대화 입력, 녹음, 번역 서비스를 제공하지 않습니다. 호스팅 제공자는 보안과 서비스 운영을 위한 접속 정보를 처리할 수 있습니다. 외부 출처 링크를 누르면 해당 사이트의 정책이 적용됩니다.

설치형 앱의 처리 방식

기본 콘텐츠와 설정·번역 캐시는 기기에 저장합니다. 서버 연결 시 임의의 익명 세션을 만들고 서버에는 토큰의 해시와 만료 정보를 보관합니다. 앱은 외부 AI 번역 전송에 동의한 경우 문장과 언어를 통해 서버를 거쳐 OpenAI로 전송합니다. 통해 API는 번역 원문·결과와 음성 파일을 저장하지 않습니다. 외부 AI 제공자의 보존·처리 조건은 별도로 적용됩니다.

기기 음성 인식은 OS 또는 음성 서비스 제공자의 처리 방식을 따릅니다. 음성이 항상 기기 안에서만 처리된다고 보장하지 않습니다. 민감한 개인정보는 입력하지 마세요.

선택적 사용 기록

기본은 꺼짐입니다. 동의한 경우에만 상황 ID·언어·기능 사용 유형·날짜와 익명 세션 연결 정보를 저장합니다. 동의 철회 시 해당 이벤트를 삭제하고 30일을 초과한 이벤트는 운영 정리 작업으로 삭제하도록 구성했습니다.

삭제

앱의 ‘앱 연결·개인정보’에서 서버 데이터 삭제와 기기 설정·캐시 삭제를 각각 실행할 수 있습니다. 서버 삭제는 네트워크 연결이 필요합니다. 실제 운영 환경의 로그·백업 보존과 운영자 연락처는 테스트 배포 전 확정할 예정입니다.

이 문서는 출시 전 안내 초안입니다. 스토어 정식 배포 전 실제 운영 환경과 제공자 설정에 맞춰 확정합니다.
